# Ionic Vanilla JavaScript Skeleton project

This is a Ionic JavaScript starter app using Vite.

Project created following [this guide](https://ionicframework.com/docs/javascript/quickstart).


## How to run it
```bash
npm run dev
```


## How to add native platforms
```bash
npm install @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android
npx cap init

npm run build

npx cap add ios
npx cap add android
```
